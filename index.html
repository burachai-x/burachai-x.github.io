แอปที่เราพัฒนาเอง

เราไม่ได้รับจ้างเขียนอย่างเดียว — เราลงมือทำแอปของตัวเองตั้งแต่ออกแบบ เขียน ทดสอบ จนถึงยื่นขึ้นสโตร์ จึงรู้ปัญหาจริงทุกขั้นตอน

รอ Google ตรวจสอบ — เร็วๆ นี้บน Google Play

DooVNow

แอปรับชมวิดีโอ YouTube บน Android ที่เบา เรียบง่าย และไม่เก็บข้อมูลคุณ

  • ไม่มี SDK โฆษณา ตัวติดตาม หรือตัววิเคราะห์พฤติกรรมฝังอยู่ในแอปเลย
  • ลงชื่อเข้าใช้เพื่อดูช่องที่ติดตามได้ โดยโทเคนเก็บไว้ในเครื่องคุณเท่านั้น ไม่ส่งมาที่เซิร์ฟเวอร์ของเรา
  • เล่นสื่อต่อเนื่องพร้อมปุ่มควบคุมบนแถบแจ้งเตือน
  • ขอสิทธิ์เท่าที่จำเป็น — ไม่ขอตำแหน่งที่ตั้ง กล้อง ไมโครโฟน หรือรายชื่อผู้ติดต่อ

ทุกข้อข้างต้นตรงกับ นโยบายความเป็นส่วนตัวที่เผยแพร่จริง ตรวจสอบได้

อยู่ระหว่างพัฒนา

วัดที่

วัดขนาดที่ดินจากภาพถ่ายดาวเทียมได้เองในไม่กี่แตะ รู้ผลเป็นไร่-งาน-ตารางวาทันที

  • วางจุดมุมที่ละจุด หรือวางกรอบ 1 ไร่แล้วลากปรับให้พอดีแปลง
  • อ่านผลเป็น ไร่ / งาน / ตารางวา และตารางเมตรพร้อมกัน
  • ไปที่แปลงด้วยตำแหน่งปัจจุบัน หรือพิมพ์พิกัดเข้าไปตรงๆ
  • สลับแผนที่แบบผสม/ดาวเทียม และดูทิศแดดของแปลงได้

ค่าที่ได้เป็นค่าประมาณจากแผนที่ ใช้แทนการรังวัดโฉนดอย่างเป็นทางการไม่ได้

อยู่ระหว่างพัฒนา

DooNang+

แอปดูซีรีส์สั้น (short drama) บน Android

  • ค้นหาชื่อเรื่อง และกรองตามหมวด — รัก แฟนตาซี ไซไฟ แอ็กชัน
  • เลือกภาษาของเนื้อหาได้ทั้งไทยและอังกฤษ
  • มีคลังส่วนตัวสำหรับเก็บเรื่องที่กำลังดูค้างไว้
  • สร้างด้วย Kotlin + Jetpack Compose เช่นเดียวกับแอปอื่นของเรา

ยังอยู่ในขั้นพัฒนา ยังไม่เปิดให้ดาวน์โหลดทั่วไป

บริการ

รับพัฒนาซอฟต์แวร์ตามความต้องการ

รับงานพัฒนาซอฟต์แวร์ให้องค์กรและธุรกิจ ตั้งแต่ออกแบบระบบ เขียนโค้ด ไปจนถึงติดตั้งบนเซิร์ฟเวอร์จริงและดูแลต่อเนื่อง

แอปมือถือ Android

พัฒนาแอปตั้งแต่ศูนย์ ปรับปรุงแอปเดิม จนถึงขั้นตอนเผยแพร่ขึ้น Google Play

เว็บแอปพลิเคชัน

เว็บระบบภายใน แดชบอร์ด และหน้าเว็บสำหรับลูกค้า ใช้งานได้ดีทั้งบนมือถือและเดสก์ท็อป

ระบบหลังบ้าน & API

ออกแบบฐานข้อมูล เขียน API และเชื่อมต่อระบบที่มีอยู่เดิมให้คุยกันได้

Odoo ERP & ระบบธุรกิจ

พัฒนาโมดูลเฉพาะทาง ปรับกระบวนการให้ตรงกับการทำงานจริง และเชื่อมข้อมูลข้ามระบบ

ตรวจสอบความปลอดภัย

ตรวจแอปและระบบหลังบ้านหาช่องโหว่ พร้อมทำ hardening ให้เซิร์ฟเวอร์และเครือข่าย

ติดตั้งและดูแลระบบ

วางระบบด้วย Docker ตั้งค่าเซิร์ฟเวอร์ สำรองข้อมูล และดูแลต่อหลังส่งมอบ

ขั้นตอนการทำงาน

เริ่มต้นง่าย ไม่มีค่าใช้จ่ายจนกว่าจะตกลงกัน

คุยความต้องการก่อนเสมอ แล้วค่อยเสนอขอบเขตงานและราคาเป็นลายลักษณ์อักษร

คุยความต้องการ

เล่าปัญหาที่อยากแก้มาได้เลย ยังไม่ต้องมีสเปกละเอียด

เสนอขอบเขต + ราคา

สรุปสิ่งที่จะได้ ระยะเวลา และค่าใช้จ่ายให้ชัดก่อนเริ่มงาน

พัฒนา ส่งงานเป็นรอบ

ทยอยส่งให้ดูและปรับระหว่างทาง ไม่ต้องรอลุ้นตอนจบ
