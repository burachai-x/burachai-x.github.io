ทำไมต้องเรา

คนออกแบบ คนเขียน และคนหาช่องโหว่ คือทีมเดียวกัน

ระบบส่วนใหญ่ไม่ได้พังเพราะโค้ดชิ้นใดชิ้นหนึ่ง แต่พังตรงรอยต่อ — ระหว่างแอปกับ API ระหว่าง API กับฐานข้อมูล ระหว่างเซิร์ฟเวอร์กับเครือข่าย เราดูทั้งเส้น

  • ทำแอปของตัวเองจนขึ้นสโตร์ — รู้ปัญหาจริงตั้งแต่ออกแบบ ทดสอบ จนถึงการตรวจของ Google Play
  • ดูแลเซิร์ฟเวอร์และเครือข่ายจริง — Docker, ไฟร์วอลล์, VPN, การ hardening และการสำรองข้อมูล
  • ถอดแอปเพื่อหาช่องโหว่เป็นงานประจำ — จึงรู้ว่าอะไรที่ผู้โจมตีเห็นได้จากไฟล์ที่คุณปล่อยขึ้นสโตร์
  • PDPA เป็นส่วนหนึ่งของการออกแบบ — ไม่ใช่เอกสารที่มาแปะทีหลังตอนตรวจ
  • ส่งมอบซอร์สโค้ด — ระบบเป็นของคุณ ไม่ผูกไว้กับเรา
  • สื่อสารเป็นภาษาคน — รายงานและข้อเสนอเขียนให้ผู้บริหารอ่านรู้เรื่อง ไม่ใช่ทิ้งผลสแกนดิบ
