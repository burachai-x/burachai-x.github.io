ผลิตภัณฑ์ของเรา

DooVNow — แอปดูวิดีโอที่เคารพความเป็นส่วนตัว

ทุกข้อด้านล่างนี้ระบุไว้ตรงกับนโยบายความเป็นส่วนตัวของแอปที่เผยแพร่จริง ตรวจสอบได้ทุกข้อ

ไม่มีโฆษณา ไม่มีตัวติดตาม

แอปไม่ฝัง SDK โฆษณา วิเคราะห์พฤติกรรม การติดตาม หรือรายงานข้อขัดข้องใดๆ ทั้งสิ้น

ล็อกอินแล้วโทเคนอยู่ในเครื่อง

ลงชื่อเข้าใช้เพื่อดูช่องที่ติดตามได้ โดยโทเคนถูกเก็บไว้บนอุปกรณ์ของคุณเท่านั้น ไม่ถูกส่งไปเซิร์ฟเวอร์ของเรา และเราไม่เห็นรหัสผ่านคุณ

เล่นต่อเนื่อง คุมจากแถบแจ้งเตือน

รองรับการเล่นสื่อแบบ foreground service พร้อมปุ่มควบคุมบนการแจ้งเตือน ฟังต่อได้ไม่สะดุด

ขอสิทธิ์เท่าที่จำเป็นจริงๆ

ขอแค่อินเทอร์เน็ต การเล่นสื่อ และการแจ้งเตือน — ไม่ขอตำแหน่งที่ตั้ง กล้อง ไมโครโฟน รายชื่อผู้ติดต่อ หรือไฟล์ส่วนตัว

ลบข้อมูลได้ด้วยตัวเอง

ออกจากระบบหรือถอนการติดตั้ง ข้อมูลที่เก็บในเครื่องทั้งหมดหายไปทันที ไม่มีอะไรค้างอยู่ที่ไหน

ไม่ขาย ไม่แชร์ข้อมูล

เราไม่ขาย ไม่ให้เช่า และไม่แบ่งปันข้อมูลของคุณกับบุคคลที่สาม การเชื่อมต่อเกิดขึ้นตรงระหว่างเครื่องคุณกับ Google/YouTube

บริการ

รับพัฒนาซอฟต์แวร์ตามความต้องการ

นอกจากผลิตภัณฑ์ของเราเอง เรารับงานพัฒนาซอฟต์แวร์ให้องค์กรและธุรกิจ ตั้งแต่ออกแบบระบบ เขียนโค้ด ไปจนถึงติดตั้งบนเซิร์ฟเวอร์จริงและดูแลต่อเนื่อง

แอปมือถือ Android

พัฒนาแอปตั้งแต่ศูนย์ ปรับปรุงแอปเดิม จนถึงขั้นตอนเผยแพร่ขึ้น Google Play

เว็บแอปพลิเคชัน

เว็บระบบภายใน แดชบอร์ด และหน้าเว็บสำหรับลูกค้า ใช้งานได้ดีทั้งบนมือถือและเดสก์ท็อป

ระบบหลังบ้าน & API

ออกแบบฐานข้อมูล เขียน API และเชื่อมต่อระบบที่มีอยู่เดิมให้คุยกันได้

Odoo ERP & ระบบธุรกิจ

พัฒนาโมดูลเฉพาะทาง ปรับกระบวนการให้ตรงกับการทำงานจริง และเชื่อมข้อมูลข้ามระบบ

ตรวจสอบความปลอดภัย

ตรวจแอปและระบบหลังบ้านหาช่องโหว่ พร้อมทำ hardening ให้เซิร์ฟเวอร์และเครือข่าย

ติดตั้งและดูแลระบบ

วางระบบด้วย Docker ตั้งค่าเซิร์ฟเวอร์ สำรองข้อมูล และดูแลต่อหลังส่งมอบ

ขั้นตอนการทำงาน

เริ่มต้นง่าย ไม่มีค่าใช้จ่ายจนกว่าจะตกลงกัน

คุยความต้องการก่อนเสมอ แล้วค่อยเสนอขอบเขตงานและราคาเป็นลายลักษณ์อักษร

คุยความต้องการ

เล่าปัญหาที่อยากแก้มาได้เลย ยังไม่ต้องมีสเปกละเอียด

เสนอขอบเขต + ราคา

สรุปสิ่งที่จะได้ ระยะเวลา และค่าใช้จ่ายให้ชัดก่อนเริ่มงาน

พัฒนา ส่งงานเป็นรอบ

ทยอยส่งให้ดูและปรับระหว่างทาง ไม่ต้องรอลุ้นตอนจบ

ส่งมอบและดูแลต่อ

ติดตั้งใช้งานจริง ส่งมอบซอร์สโค้ด พร้อมช่วงดูแลหลังส่งมอบ
